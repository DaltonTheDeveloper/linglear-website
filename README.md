# Linglear Website

A Next.js implementation of the Linglear marketing site and logged-in dashboard
mockups. The project follows the glassmorphism + neon aesthetic described in
the product outline and includes dedicated routes for each public and
authenticated page.

## Getting Started

```bash
npm install
npm run dev
```

The app will be available at [http://localhost:3000](http://localhost:3000).

## Available Pages

- `/` – Home / Landing
- `/alpha-signup` – Alpha onboarding
- `/features` – Feature overview
- `/pricing` – Pricing tiers
- `/community` – Public community hub
- `/how-it-works` – Timeline & transparency
- `/faq` – Frequently asked questions
- `/contact` – Contact form
- `/dashboard` – Logged-in dashboard mock
- `/watchlist` – Watchlist mock
- `/learning` – Word bank mock
- `/community/logged-in` – Logged-in community hub
- `/settings` – Account settings

All pages are static representations ready for future data integrations.
